Роль: Ты Senior Frontend разработчик и архитектор с глубоким знанием React, TypeScript и Redux Toolkit.

Задача: Создай готовую к продакшену базовую архитектуру и конфигурацию для стейт-менеджера Redux Toolkit в связке с TypeScript. Этот сетап должен быть масштабируемым.

Предоставь пошаговое руководство, включая команды установки, древовидную структуру папок и код для каждого файла.

src/
├── hooks/
│ └── useRedux.ts
├── store/
│ ├── reducers/
│ │ ├── actions/
│ │ │ └── userActions.ts # Пример для асинхронных санков
│ │ └── slices/
│ │ └── userSlice.ts # Пример слайса
│ └── store.ts
├── index.tsx # Или main.tsx / index.ts
└── App.tsx

Технические требования и структура:

1. Установка: Покажи команды установки необходимых библиотек через npm и yarn (@reduxjs/toolkit, react-redux).

2. Структура папок: Архитектура внутри `src` должна строго соответствовать следующему виду:
   - src/store/store.ts (главный файл конфигурации)
   - src/store/reducers/slices/ (папка для слайсов)
   - src/store/reducers/actions/ (папка для асинхронных экшенов / санков)
   - src/hooks/useRedux.ts (кастомные хуки)
     при необходимости можешь дополнить папками и файлами

3. Настройка и типизация Store (store.ts):
   - Настрой конфигурацию хранилища с помощью configureStore.
   - Экспортируй типы RootState и AppDispatch, автоматически вычисляемые из самого store.

4. Кастомные хуки (useRedux.ts):
   - Создай и экспортируй строго типизированные хуки useAppDispatch и useAppSelector, используя типы TypedUseSelectorHook, RootState и AppDispatch.

5. Примеры типизации (в папке reducers):
   - Напиши один пример реального асинхронного экшена (createAsyncThunk) в папке actions (например, fetchUser) с явным указанием типов для возвращаемых данных, аргументов и обработки ошибок через thunkAPI.
   - Напиши пример слайса (createSlice) в папке slices, который обрабатывает этот асинхронный экшен (состояния pending, fulfilled, rejected) и один синхронный экшен (например, clearData). Используй PayloadAction для типизации экшенов.

6. Обертка приложения:
   - Покажи, как правильно обернуть корневой файл приложения (index.tsx или main.tsx) в компонент Provider из react-redux, передав туда созданный store.

Требования к коду:

- Пиши код на TypeScript, соблюдая strict mode (никаких any, все типы должны быть явно указаны или безопасно выведены).
- Используй современный синтаксис Redux Toolkit (extraReducers с использованием builder).
- Код должен быть чистым, снабжен краткими комментариями и готов к копированию.
